Laborator Algoritmi Paraleli și Distribuiți – rezolvarea exercițiilor

Exercițiul 1

Pentru o singură imagine avem task-urile: A – citirea căii fișierului, B – încărcarea imaginii, C – transformarea în nivele de gri, D – salvarea imaginii. Mulțimile de intrare (I) și ieșire (O):

  • A: IA = {sourceDirectory}, OA = {fileName}
  • B: IB = {fileName}, OB = {image}
  • C: IC = {image}, OC = {image}
  • D: ID = {image, finalDirectory}, OD = {fișierul salvat}

Graful dependențelor:

{{G1}}

OA ∩ IB = {fileName} ≠ Φ, OB ∩ IC = {image} ≠ Φ, OC ∩ ID = {image} ≠ Φ, deci între task-uri există dependențe prin succesiune (A → B → C → D) și condițiile lui Bernstein nu sunt îndeplinite. Fiecare task are nevoie de rezultatul celui dinainte, așa că pentru o singură imagine problema nu se poate paraleliza la nivel de task-uri. Doar în interiorul lui C pixelii sunt independenți între ei, dar toți se află în același obiect Bitmap.

Exercițiul 2

Pentru un set de imagini, Task A (lista de fișiere) se execută o singură dată, apoi pentru fiecare imagine i se execută lanțul Bi → Ci → Di:

{{G2}}

Lanțurile pentru imagini diferite lucrează pe fișiere și obiecte Bitmap diferite, deci pentru i ≠ j: Ii ∩ Oj = Φ, Ij ∩ Oi = Φ, Oi ∩ Oj = Φ. Condițiile lui Bernstein sunt îndeplinite, așa că după Task A imaginile se pot procesa în paralel: fiecare thread preia o parte din imagini.

Exercițiul 3

Lista de imagini se împarte în N partiții consecutive. Threadul cu indexul tid procesează imaginile de la tid·n/N până la (tid+1)·n/N − 1, unde n este numărul de imagini:

//atentie la calea de pe disk unde se afla imaginile!!!
public static string sourceDirectory = @"C:\Studenti\SourceImages";
public static string finalDirectory = @"C:\Studenti\FinalImages";
public static string[] fileEntries; //lista partajata
public static int N;

public static void ThreadFunction(object parameter)
{
    int tid = (int)parameter;
    int start = tid * fileEntries.Length / N;
    int stop = (tid + 1) * fileEntries.Length / N;

    for (int i = start; i < stop; i++)
    {
        string fileName = fileEntries[i];
        using (Bitmap image = new Bitmap(fileName)) //Task B
        {
            for (int x = 0; x < image.Width; x++)  //Task C
            {
                for (int y = 0; y < image.Height; y++)
                {
                    Color pixelColor = image.GetPixel(x, y);
                    int gray = (pixelColor.R + pixelColor.G + pixelColor.B) / 3;
                    Color newColor = Color.FromArgb(gray, gray, gray);
                    image.SetPixel(x, y, newColor);
                }
            }
            image.Save(Path.Combine(finalDirectory, Path.GetFileName(fileName))); //Task D
        }
    }
}

Cu trei threaduri (varianta cu două threaduri este la fel, fără th3 și cu N = 2):

static void Main(string[] args)
{
    fileEntries = Directory.GetFiles(sourceDirectory, "*.bmp").OrderBy(x => x).ToArray(); //Task A
    N = 3;

    Thread th1 = new Thread(ThreadFunction);
    Thread th2 = new Thread(ThreadFunction);
    Thread th3 = new Thread(ThreadFunction);
    th1.Start(0); //parametru - indexul partitiei
    th2.Start(1);
    th3.Start(2);
    th1.Join();
    th2.Join();
    th3.Join();
}

Cu N threaduri, unde N se dă ca parametru la rularea aplicației (în Visual Studio: Project → Properties → Debug → Command line arguments):

static void Main(string[] args)
{
    fileEntries = Directory.GetFiles(sourceDirectory, "*.bmp").OrderBy(x => x).ToArray(); //Task A
    N = int.Parse(args[0]);

    Thread[] threads = new Thread[N];
    for (int i = 0; i < N; i++)
    {
        threads[i] = new Thread(ThreadFunction);
        threads[i].Start(i); //parametru - indexul partitiei
    }
    for (int i = 0; i < N; i++)
    {
        threads[i].Join();
    }
}

Exercițiul 4 – alocarea dinamică a task-urilor

Threadurile nu mai primesc o partiție fixă. Fiecare thread ia din listă următoarea imagine neprocesată, o marchează ca preluată (șir gol) și, după ce o termină, ia alta. Accesul la listă se face exclusiv, cu lock:

static object _lock = new object();

public static void ThreadFunction(object parameter)
{
    int tid = (int)parameter;
    while (true)
    {
        string fileName = string.Empty;
        lock (_lock)
        {
            for (int i = 0; i < fileEntries.Length && fileName == string.Empty; i++)
            {
                if (fileEntries[i] != string.Empty)
                {
                    fileName = fileEntries[i];
                    fileEntries[i] = string.Empty; //imaginea a fost preluata
                }
            }
        }
        if (fileName == string.Empty)
            break; //nu mai sunt imagini de procesat

        using (Bitmap image = new Bitmap(fileName)) //Task B
        {
            ... //Task C si Task D, ca la exercitiul 3
        }
    }
}
