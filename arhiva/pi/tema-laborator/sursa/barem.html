Subiectul I – Teorie (3 p)

  1. (1 p) Obiectivă: valoarea e calculată cu o formulă (funcție de măsură), nu dată de observatori umani; subiectivă: notă dată de observatori (0,25 p). Cu referință: imaginea testată/degradată f se compară cu imaginea originală nedegradată f0, se măsoară fidelitatea față de referință (0,5 p). Fără referință: calitatea se apreciază doar din f, fără original (0,25 p).
  2. (1 p) Formulele (cu sumele după m = 0..M−1, n = 0..N−1), 0,15 p fiecare:
    MSE = (1/MN)·ΣΣ (f(m,n) − f0(m,n))2;   MAE = (1/MN)·ΣΣ |f(m,n) − f0(m,n)|;
    SNR = 10·log10[ ΣΣ f02(m,n) / ΣΣ (f(m,n) − f0(m,n))2 ] [dB];   PSNR = 10·log10[ MN·max f02(m,n) / ΣΣ (f(m,n) − f0(m,n))2 ] [dB].
    Când calitatea crește: MSE și MAE scad, SNR și PSNR cresc (0,2 p). PSNR > SNR deoarece fiecare f02(m,n) ≤ max f02, deci MN·max f02 ≥ ΣΣ f02(m,n), iar numitorul e același (0,2 p).
  3. (1 p) MSE compară pixel cu pixel și nu ține cont de vecinătate/structură; distorsiuni diferite (zgomot, blur, compresie, deplasare de luminozitate) pot da aceeași MSE, dar arată foarte diferit (0,4 p). SSIM compară luminanța, contrastul și structura, folosind medii locale, dispersii locale și corelația locală (integrează contextul spațial) (0,3 p). Proprietăți: simetrie S(x,y) = S(y,x); valori în [0, 1]; maxim unic: S(x,y) = 1 doar dacă x = y (0,15 p pentru fiecare, max. 0,3 p).

Subiectul II – Calcul (2,5 p)

Erorile f − f0 sunt nenule doar în 4 pixeli: +12, −6, +6, −12. ΣΣ e2 = 144 + 36 + 36 + 144 = 360; ΣΣ |e| = 36; ΣΣ f02 = 8·1002 + 2002 = 120000; max f0 = 200; MN = 9.

  1. (1 p) MSE = 360 / 9 = 40 (0,5 p); MAE = 36 / 9 = 4 (0,5 p).
  2. (1 p) SNR = 10·log10(120000 / 360) = 10·log10(333,3) ≈ 25,23 dB (0,5 p); PSNR = 10·log10(9·2002 / 360) = 10·log10(1000) = 30 dB (0,5 p). Dacă se folosește 255 în loc de max f0 (PSNR ≈ 32,11 dB) se acordă 0,25 p.
  3. (0,5 p) SNR > 25 dB, deci imaginea este „de calitate” (0,25 p); SNR < 30 dB, deci diferențele față de original pot fi încă perceptibile (0,25 p).

Subiectul III – Python (3,5 p)

Soluție de referință (rulată; valorile depind puțin de zgomotul generat):

import numpy as np
import math
import matplotlib.pyplot as plt
from skimage import io, color
from scipy import signal

def mse(f0, f):
    h, w = f0.shape
    return np.sum((f - f0) ** 2) / (h * w)

def snr(f0, f):
    return 10 * math.log10(np.sum(f0 ** 2) / np.sum((f - f0) ** 2))

def psnr(f0, f):
    h, w = f0.shape
    return 10 * math.log10(h * w * np.max(f0) ** 2 / np.sum((f - f0) ** 2))

img = io.imread('lena.png')
img = color.rgb2gray(img) * 255          # f0, gama [0,255]
h, w = img.shape
N = np.random.normal(0, 10, (h, w))
img_noise = img + N
mask = np.ones([3, 3]) / 9
img_filt = signal.convolve2d(img_noise, mask, mode='same', boundary='symm')
plt.figure(), plt.imshow(img_noise, cmap='gray')
plt.figure(), plt.imshow(img_filt, cmap='gray')
print('zgomotoasa:', mse(img, img_noise), snr(img, img_noise), psnr(img, img_noise))
print('filtrata:  ', mse(img, img_filt), snr(img, img_filt), psnr(img, img_filt))
  1. (1,5 p) mse, snr, psnr câte 0,5 p. Se acceptă și variantele cu bucle for sau cu ignorarea marginilor (capat, ca în Lab 4), precum și 255 în loc de np.max(f0) la PSNR (varianta din Lab 4). Calcul pe uint8 fără conversie la float (diferența dă overflow): −0,25 p.
  2. (1,5 p) citire + nivele de gri în [0, 255] (0,25 p); zgomot gaussian adăugat (0,25 p); masca 3×3 cu toți coeficienții 1/9 și filtrarea (0,5 p); afișarea celor două imagini (0,25 p); calculul măsurilor pentru ambele imagini (0,25 p).
  3. (0,5 p) Valori așteptate (±0,2): zgomotoasă MSE ≈ 100 (≈ σ2), SNR ≈ 22,1 dB, PSNR ≈ 27,8 dB; filtrată MSE ≈ 41,6, SNR ≈ 25,9 dB, PSNR ≈ 31,6 dB (cu 255: PSNR ≈ 28,1 și 31,9 dB). Filtrarea îmbunătățește calitatea: MSE scade de aproximativ 2,4 ori, SNR și PSNR cresc cu aproximativ 3,8 dB (0,25 p). Imaginea zgomotoasă nu este de calitate (SNR < 25 dB), cea filtrată este (SNR > 25 dB), dar diferențele (ușoară încețoșare) rămân vizibile, SNR < 30 dB (0,25 p).
